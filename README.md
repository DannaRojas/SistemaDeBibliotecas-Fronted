# Sistema de bibliotecas - Frontend

Frontend Angular del taller de bibliotecas y libros.

## Requisitos implementados

- Modelos Biblioteca y Libro.
- Servicio HTTP para consultar y registrar bibliotecas.
- Formulario para registrar una biblioteca con nombre, dirección y ciudad.
- Tabla de libros con título, autor, año y biblioteca asociada.

## Ejecutar

Primero inicia el backend en `http://localhost:8080`.

En esta carpeta ejecuta:

```powershell
npm start
```

Abre `http://localhost:4200`.
